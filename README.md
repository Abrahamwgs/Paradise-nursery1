# Paradise Nursery

Paradise Nursery is a React shopping-cart application for an online houseplant shop. Users can browse houseplants by category, add plants to their cart, change quantities, remove items, and view cart totals.

## Features
- Landing page with a background image and Get Started button
- Company information page
- Three houseplant categories with six plants per category
- Redux Toolkit cart state management
- Dynamic cart item count and cart totals
- Quantity controls, remove buttons, checkout placeholder, and continue shopping

## Tech Stack
- React
- Vite
- React Router
- Redux Toolkit
- React Redux
- CSS

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.
